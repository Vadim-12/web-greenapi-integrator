# Messenger UI — тестовое задание

Клиент чатов на React + TypeScript, созданный через `npm create vite@latest -- --template react-ts`.
Поддерживает отдельные рабочие пространства Telegram, WhatsApp и MAX через GREEN-API. Без подключения доступен демонстрационный режим.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://127.0.0.1:5173`).

## Как проверить реальный Telegram

1. Создайте и авторизуйте Telegram-инстанс в [GREEN-API Console](https://console.green-api.com).
2. В приложении выберите **TG** → нажмите шестерёнку.
3. Введите адрес API, ID инстанса и токен → **Подключить**.
4. Выберите чат или создайте новый, указав реальный Telegram `chatId`.

Без настроек включается демо-режим: сообщения существуют только в браузере и не отправляются в мессенджер.

## Что умеет приложение

- поиск и создание диалогов;
- быстрый показ последних 50 сообщений с фоновой загрузкой доступной истории;
- подгрузка предыдущих сообщений при прокрутке к началу ленты;
- обновление списка чатов, превью, уведомлений и статусов исходящих;
- отправка текста и файлов, повторная отправка текстового сообщения при ошибке;
- изображения, видео, видеосообщения, аудио и документы в истории;
- непрочитанные сообщения, статусы исходящих, индикатор набора текста;
- скелетоны, обработка ошибок и клавиатурная навигация модальных окон;
- аватар активного чата — только по открытию, чтобы не расходовать квоту API.

## Важные ограничения GREEN-API

- `getChatHistory` принимает только количество, без cursor/offset. Поэтому приложение сначала показывает 50 последних сообщений, а затем догружает в кэш всю историю, которую вернул API, и раскрывает её частями по 50 при прокрутке вверх.
- GREEN-API хранит медиафайлы ограниченное время (в документации указан срок 24 часа). Для устаревшего медиа API может не вернуть рабочую ссылку; приложение пытается обновить её методом `downloadFile` один раз.
- На бесплатном Developer-тарифе некоторые методы, включая получение аватара, могут вернуть HTTP 466 при исчерпании квоты. В таком случае отображаются инициалы контакта.
- Ключи сохраняются в `localStorage` браузера, чтобы соединение переживало обновление страницы. Это допустимо для тестового фронтенда, но в production запросы к GREEN-API и токены нужно вынести в серверную прослойку.

## Архитектура

Упрощённый FSD-подход:

```text
src/
  app/                 # точка входа
  pages/messenger/     # сценарии и композиция страницы
  widgets/             # сайдбар и окно диалога
  entities/            # chat, message
  features/            # подключение, создание чата, отправка, история, уведомления
  shared/              # Axios-клиент GREEN-API, конфигурация, утилиты и типы
```

## Проверки

```bash
npm run lint
npm test
npm run test:e2e
npm run test:all
npm run build
```

Unit- и integration-тесты запускаются в Vitest; e2e — в Playwright. Реальные запросы к GREEN-API в тестах не выполняются: HTTP-клиент проверяется через мок Axios.
